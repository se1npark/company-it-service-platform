# VPN Troubleshooting

## Symptoms

- VPN client shows connected but internal apps time out.
- File shares or CRM are unreachable.
- User can browse the internet but cannot access company resources.
- Issue happens only from home Wi-Fi.

## First-Line Checks

1. Confirm the user can authenticate to VPN.
2. Compare home Wi-Fi with a mobile hotspot.
3. Test DNS resolution for internal hostnames.
4. Confirm the user is in the correct VPN access group.
5. Refresh the VPN profile or routes.
6. Ask whether the password changed recently.

## Escalate When

- Multiple users in one location are affected.
- Internal DNS fails for many hostnames.
- VPN client logs show policy or certificate errors.
