# Software Installation Policy

## Purpose

This guide explains how support agents should handle software installation requests.

## First-Line Checks

1. Confirm the business reason.
2. Check whether the software is already approved.
3. Confirm licence availability.
4. Check compatibility with Windows and managed devices.
5. Use the software deployment tool where available.
6. Avoid granting local admin rights unless explicitly approved.

## Escalate When

- A new licence purchase is required.
- Security review is needed.
- The installer requires unsupported system changes.
