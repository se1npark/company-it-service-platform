# New Starter Account Setup

## Required Inputs

- Legal name and preferred display name
- Start date
- Department and job title
- Manager
- Location
- Required application access
- Hardware requirements

## Checklist

1. Create Microsoft Entra ID user account.
2. Assign Microsoft 365 licence.
3. Add department and role-based groups.
4. Enable Teams and email access.
5. Add VPN access if approved.
6. Assign laptop and peripherals.
7. Send first-login instructions.
8. Confirm first-day sign-in.

## Escalate When

- Manager approval is missing.
- Licence availability is insufficient.
- A privileged role or sensitive application is requested.
